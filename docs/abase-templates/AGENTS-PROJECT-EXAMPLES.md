# AGENTS.md Project Examples

When copying this repo as a template, replace the project description and deliverable in AGENTS.md with your project's values.

## Example: Django blog

```markdown
## Project goal

- **Deliverable**: a simple Django blog (posts, optional auth, listing/detail pages, clean structure).
- **Process**: work is tracked in Beads; epics and tasks can be created up front or discovered as we build.
```

## Example: API service

```markdown
## Project goal

- **Deliverable**: a REST API service (FastAPI or Django REST) with auth and core endpoints.
- **Process**: work is tracked in Beads; use the rules in .cursor/rules/ (especially abase-agentic-workflow.mdc).
```

## Example: Static site

```markdown
## Project goal

- **Deliverable**: a static marketing site (Astro, Next.js, or similar).
- **Process**: work is tracked in Beads; use the rules in .cursor/rules/.
```
